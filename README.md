# VYB Nutrition Assistant

## Assumptions Made
- Recipes are for 3-4 people.
- Standard serving size for Wet Sabzi is approximately 180g.
- Ingredient weights are approximated based on common household measurements.

## Modularization Approach
- The code is organized into functions for fetching recipes, converting measurements, and calculating nutrition.
- Each function handles a specific task to ensure clarity and maintainability.

## Input/Output Examples
### Input
- Dish Name: "Paneer Butter Masala"

### Output
```json
{
  "estimated_nutrition_per_200ml_katori": {
    "calories": "280.00",
    "protein": "12.00",
    "carbs": "10.00",
    "fat": "18.00"
  },
  "dish_type": "Wet Sabzi",
  "ingredients_used": [
    { "ingredient": "Paneer", "quantity": "0.75 cup" },
    { "ingredient": "Butter", "quantity": "2 tsp" },
    { "ingredient": "Tomato", "quantity": "0.5 cup" },
    { "ingredient": "Onion", "quantity": "0.5 cup" },
    { "ingredient": "Cream", "quantity": "1 tbsp" }
  ]
}
